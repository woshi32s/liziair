VST3 插件

结论先说：在应用内直接加载 VST3 做不到，不是没实现，是浏览器沙箱不允许。

  • AudioWorklet 调不了原生模块 —— 它的全局作用域里没有 require / module / window，加载不了 .node
  • npm 上没有可用的 Node VST3 宿主 —— node-vst3-host / vst3-host / vst3-js 全是 404，node-vst 停在 0.0.1
  • VST3 SDK 是 GPLv3 或 Steinberg 专有双许可，闭源宿主得签协议
  • GUI 才是死结 —— 本机实测 Saturn 2 有 956 个参数、Timeless 3 有 1012 个，没有插件自己的界面就是不能用

能跑的只有外部宿主：独立进程加载 VST3，音频走虚拟声卡。

pip install pedalboard
python -c "from pedalboard import load_plugin; p=load_plugin(r'C:\Program Files\Common Files\VST3\FabFilter\FabFilter Pro-Q 4.vst3'); print(p.name)"

本机实测：107 个商业插件里 101 个能加载并处理音频（94%），性能中位 32 倍实时。

这个入口先留白。要真接，下一步是写一个常驻的 VST 宿主进程 + 音频环回，跟应用内播放分开。
