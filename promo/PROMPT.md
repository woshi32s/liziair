# LIZI 宣传片 · 提示词与素材

> 用法：把工作目录指到 `promo/`（或把 `assets/` 里的图传进对话），粘「主提示词」。
> 里面只给事实和素材，镜头/剪辑/节奏/音乐都由它决定。
> 素材是静帧；形态那批每张代表一种"会动的机制"，运动方式让它自己想象。

---

## 主提示词（直接粘）

```
项目：LIZI，一个桌面音乐播放器（Windows / Electron）。
它接网易云歌单，把正在播的歌词实时变成 235 种可视化形态。
一句话概括：同一首歌，235 种长的样子。

视觉基调（这些是硬的，别的随你）：
纸白 #fdfcfa、墨黑 #17171a，唯一强调色是网易云红 oklch(62% .22 12)。
1px 细线、极小圆角、大量留白，整体像印刷品/编辑部版式。
不要霓虹、不要玻璃拟态、不要彩虹渐变、不要 emoji、不要 3D 弹跳图标。

素材在 assets/，共 23 张 1440×900：
- 00-logo.png：应用图标
- 01~08：界面截图（大厅、海报悬停、播放页、DJ 台、转盘特写、我的专辑 3D 架、专辑特写、设置页）
- 10~23：歌词可视化的 13 种形态（蜂蜡、水拓、莳绘、熔岩、铅字、等高线、体素、青瓷、投影、纸浆、断层、汞、枯山水、体积步进）

成片：25 秒，16:9。
剪辑、镜头、节奏、音乐、转场全部交给你发挥，我不干涉。
只有一个要求：结尾落在 00-logo，并给「235 种形态」这句话留出读得完的时间。

其它可用的数字（需要时挑着用）：6 个音源（网易云 / QQ / 酷狗 / 汽水 / 波点 / Spotify）、
7 段 EQ + 10 套预设、每个形态都是实时渲染。
```

---

## 另一版：15 秒竖版 9:16

```
同一支片压成 15 秒 9:16 竖版，素材同上（assets/ 里 00~08、10~23 都能用）。
同样：纸白墨黑 + 一点网易云红，像印刷品，不要霓虹和玻璃拟态。
剪辑与镜头你定，结尾落 logo。
```

## 可选文案（它要文字时给）

> 一首歌，235 种样子。
> 同一句词，可以是纸上的压痕、瓷上的开片、汞里的倒影、霜花、熔岩、或者一场枯山水。
> LIZI 把网易云的歌单接进来，让歌词自己决定长成什么。
> 235 种形态，一首歌的样子。
